# CRM Application to Manage Clients & Property Requirements (Salesforce)

This project is a **Customer Relationship Management (CRM)** application built using **Salesforce Platform** to help real estate businesses manage client data, property requirements, meetings, and follow-ups in a structured way.

---

## 🚀 Project Overview

This CRM system allows users to:
- Store and manage detailed client information.
- Record and track property requirements.
- Schedule meetings and log updates.
- Automate follow-ups and lead tracking.

It improves workflow efficiency and provides a central place to monitor interactions with clients.

---

## 🧠 Motivation

Real estate agencies often struggle to manage leads and client data across spreadsheets or multiple systems. This Salesforce-based CRM provides a streamlined way to:
- Replace manual processes
- Improve team collaboration
- Track client engagement easily

---

## 💡 Key Features

✔ Client and contact management  
✔ Property requirement tracking  
✔ Meeting and follow-up scheduling  
✔ Lead status updates and automation  
✔ Centralized data for easy access

---

## 🛠 Tech Stack

This project uses the following technologies:

- **Salesforce Platform** (CRM)
- **Lightning Web Components (LWC)**
- **Salesforce CLI + VS Code**
- Apex, SOQL, SOSL  
- Automation using Process Builder & Flows
